# Curated repositories

This is a list of cureated repositories by Justin Leemans. These are some projects that I find interesting, packages that I use regularly or just cool projects that I want to support

# Unity

## [GlitchEnzo/NuGetForUnity](https://github.com/GlitchEnzo/NuGetForUnity)

Add NuGet to Unity to allow importing of native C# libraries

## [Unity-Technologies/ProjectAuditor](https://github.com/Unity-Technologies/ProjectAuditor)

Unity project auditing tool, get suggestions to improve performance of your project

## [neuecc/UniRx](https://github.com/neuecc/UniRx)

Reactive properties library for Unity (Archived, use R3 instead, see below)

## [Cysharp/R3](https://github.com/Cysharp/R3)

Reactive properties library for Unity, made by the same person behind UniRx, use this instead (Requires installation through NuGetForUnity)

## [Cysharp/UniTask](https://github.com/Cysharp/UniTask)

Better async task package for Unity, more performant and unallocated tasks

## [Mathijs-Bakker/Extenject](https://github.com/Mathijs-Bakker/Extenject)

Dependancy injection framework for Unity

## [Jeffan207/usyrup](https://github.com/Jeffan207/usyrup)

Lightweight dependancy injection framework for Unity

## [Kmiecis/Unity-Package-DynamicInjection](https://github.com/Kmiecis/Unity-Package-DynamicInjection)

Lightweight dependency injection package for Unity

## [hadashiA/VContainer](https://github.com/hadashiA/VContainer)

GC free dependency injection library for Unity

## [RiptideNetworking/Riptide](https://github.com/RiptideNetworking/Riptide)

Simple low level networking library for Unity, event based

## [PurrNet/PurrNet](https://github.com/PurrNet/PurrNet)

Hands of Unity networking solution

## [rlabrecque/Steamworks.NET](https://github.com/rlabrecque/Steamworks.NET)

Steamworks C# wrapper, build for Unity but useable as native C# library

## [dbrizov/NaughtyAttributes](https://github.com/dbrizov/NaughtyAttributes)

Powerfull attributes to extend Unity editor

## [getsentry/sentry-unity](https://github.com/getsentry/sentry-unity)

Remote bug tracking and logging tool, package for Unity

## [starikcetin/Eflatun.SceneReference](https://github.com/starikcetin/Eflatun.SceneReference)

Unity extension to add scene reference classes which makes it easier to work with scenes

# PHP

## [RobThree/TwoFactorAuth](https://github.com/RobThree/TwoFactorAuth)

A two factor authenticator for PHP projects

## [mpdf/mpdf](https://github.com/mpdf/mpdf)

A very popular pdf generation package for PHP

## [mpdf/qrcode](https://github.com/mpdf/qrcode)

A QR code generator for PHP projects

# NPM/Node

## [mrdoob/three.js](https://github.com/mrdoob/three.js)

A very popular 3d plugin for node. Allows you to render 3d objects on web pages.

# Other

## [appwrite/appwrite](https://github.com/appwrite/appwrite)

Plug and play backend for projects, similar to something like firebase

## [defold/defold](https://github.com/defold/defold)

Alternative open source game engine. Build by the people behind Candy Crush

## [stijndelaruelle/GLUFramework](https://github.com/stijndelaruelle/GLUFramework)

Small scale game engine made by one of my old teachers. Used to teach the fundamentals of game development
